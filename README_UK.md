# Кур’єр ІФ — будинки та під’їзди

Перша версія Telegram-бота для Render: адреса → точний адресний результат OSM → координати, геолокація, посилання OSM/Google Maps, PNG-схема будинку й входів.

Це намальована схема за даними OpenStreetMap, а не скрін стандартного шару сайту і не фотографія фасаду. Сусідні будинки та дороги показані для орієнтиру. Відсутні дані не вгадуються. Пошук обмежений прямокутником міста й найближчих околиць; геокодер може не знати адресу або знайти лише адресну точку без контуру. Корпуси вводьте так, як вони записані в OSM: 42А або 42/1. Окремого пошуку квартири немає.

## 1. GitHub
Створіть окремий репозиторій, наприклад if-courier-bot. Розпакуйте архів і завантажте файли з папки courier_bot в корінь репозиторію (bot.py має бути в корені). Обов’язково додайте DejaVuSans.ttf і FONT_LICENSE.txt. Токен до GitHub не завантажуйте.

## 2. Render
New → Web Service → ваш новий репозиторій.
- Language: Python
- Build Command: pip install -r requirements.txt
- Start Command: python bot.py
- Health Check Path: /
- Один екземпляр сервісу.

Environment:
- BOT_TOKEN — токен НОВОГО бота з BotFather.
- WEBHOOK_SECRET — придумайте випадковий секрет: 32–64 латинські літери й цифри, без пробілів. Не використовуйте приклад із публічного репозиторію.
- OSM_CONTACT — ваша контактна електронна адреса або URL сторінки з контактами (рекомендовано).
- ALLOWED_USER_IDS — ваш числовий Telegram ID (рекомендовано для особистого бота); кілька ID — через кому. Якщо порожньо, бот доступний всім. Щоб дізнатись ID, спочатку запустіть без цього параметра, надішліть /start, потім додайте ID й повторіть Deploy.

Render автоматично задає PORT та RENDER_EXTERNAL_URL. Якщо RENDER_EXTERNAL_URL недоступний, додайте WEBHOOK_URL=https://назва-вашого-сервісу.onrender.com (без /webhook). Бот встановлює webhook сам. Не підключайте токен цього бота до іншої програми.

Натисніть Create Web Service, дочекайтеся Live, відкрийте нового бота → /start → надішліть реальну адресу.

Для роботи без засинання потрібен тариф Render із постійною роботою. Безкоштовний Web Service може засинати, тому перша відповідь після простою затримується. Нового платного сервісу цей комплект автоматично не створює.

## 3. Перевірка
Спробуйте відому вам адресу, адресу з під’їздом і вигаданий номер будинку. Звірте під’їзд із картою на місці. Бот не повинен підміняти невідомий номер центром вулиці. Якщо входу немає в даних або номер неоднозначний, геолокація вказує будинок.

## Дані й обмеження
Входи пов’язуються з будинком через спільні вузли контуру OSM. Сусідні входи не приписуються цьому будинку. Для складних відношень OSM можуть бути неповні дані. Схема показує номери ref, а ненумеровані входи — знаком ?. Збереження власних під’їздів у цю версію не включене.

Nominatim: https://operations.osmfoundation.org/policies/nominatim/
Публічний сервер допускає максимум 1 запит/секунду на весь застосунок; потрібні ідентифікація, атрибуція і кеш. Тут запити серіалізовані з інтервалом 1,1 секунди, результати кешуються на добу; немає автодоповнення чи масового сканування. Використовуйте для особистого/помірного навантаження, не масштабуйте на кілька екземплярів. Для широкого використання потрібен інший або власний геокодер.

Кеш у ./data/cache.db містить лише публічні картографічні дані; на Render без диска він може зникати при перезапуску. Для збереження кешу між деплоями підключіть persistent disk і DATA_DIR=/var/data. NOMINATIM_URL та OVERPASS_URL дозволяють змінити провайдера без зміни коду. Растрові тайли OSM не завантажуються.
